DÜNYA Kompresör Envanter - Android Projesi

Bu proje Android Studio ile açılıp APK olarak derlenmek üzere hazırlanmıştır.
Uygulama mevcut online DÜNYA Kompresör Envanter adresini Android WebView içinde tam ekran açar.
Chrome adres çubuğu görünmez. Supabase'deki mevcut kullanıcı ve stok verileri aynen kullanılmaya devam eder.

APK DERLEME:
1. Bilgisayara Android Studio kurun.
2. Android Studio > Open ile bu klasörü seçin.
3. Gradle senkronizasyonunun tamamlanmasını bekleyin.
4. Build > Build App Bundle(s) / APK(s) > Build APK(s) seçin.
5. Oluşan debug APK genellikle app/build/outputs/apk/debug/app-debug.apk konumundadır.

Not: Bu kaynak paket APK'nın kendisi değildir. APK'nın Android SDK/Gradle ile derlenmesi gerekir.
